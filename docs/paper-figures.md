# Paper Figures And Required Data

The paper will include three figure families, generated by
`scripts/analyze_paper_figures.py` from raw sample JSONL. We do not hand-enter
figure values.

## 1. Performance Versus Tokens

Scatter plot:

- x-axis: average reported total tokens per sample
- y-axis: strict accuracy (oracle-compliant samples divided by all samples)
- marker: thinking enabled versus direct-answer inference
- color: provider/model family
- annotation: model + task/category

This requires exact provider usage where available: input tokens, output
tokens, reasoning tokens, total tokens, cache reads/misses, and latency. If a
provider omits an exact field, the row remains in the raw data but the figure
does not impute it.

## 2. Response Breakdown

Stacked bars overall and per task category:

- correct oracle-compliant move
- legal but wrong move
- illegal move
- parse error
- no answer

Fallback answers are retained as a separate per-sample field and counted in
the table, so a forced/random fallback cannot be mistaken for native model
behavior.

## 3. Accuracy Heatmap

Rows are task categories and columns are models. Cells contain strict
accuracy, with sample count and missing-usage counts in the accompanying
`paper_cells.csv` and `figure_data.json` files.

Current category mapping:

- `mate1-lichess`, `mate2-lichess`: Short Tactics
- `bestmove-8x8`: Position Judgment
- future ChessQA-style tasks will add Structural, Motifs, and Semantic

## Per-Sample Contract

Every new sample JSONL record carries:

- run/model/task/category/representation identifiers
- exact prompt and model input
- complete returned thinking text and final answer
- oracle/correct answer, parser format, verdict, compliance, fallback type
- `token_usage`: input, output, reasoning, total, cache read/write/miss,
  time-to-first-token, generation seconds, and token rates
- position metadata: FEN, puzzle id, rating, themes, opening tags, Stockfish
  cp/depth/knodes/PV when available

The same record is normalized into the public Hugging Face report JSON, so
paper analysis can be rerun from cloud artifacts without depending on the
local machine.
